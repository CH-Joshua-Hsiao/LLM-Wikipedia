# High Bandwidth Memory (HBM)

**Type**: Concept
**Sources**: [semiconductor-industry-news-april-2026.md](raw/semiconductor-industry-news-april-2026.md)

## Overview
High Bandwidth Memory (HBM) is a high-performance RAM interface for 3D-stacked SDRAM. It is completely essential for modern AI accelerators (like those from [Nvidia](Nvidia.md)) to prevent the processor from being starved for data. 

## Market Dynamics
The massive [AI Supercycle](AI_Supercycle.md) has triggered an HBM "supercycle", driving major capital expenditure booms for manufacturers like [Micron](Micron.md), SK Hynix, and Samsung. The latest generation as of 2026, HBM4, is a central focus due to its energy efficiency improvements which are critical for power-constrained AI data centers. To build HBM, these manufacturers require advanced semiconductor tooling from suppliers like [ASML](ASML.md).
